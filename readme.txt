This code simulates and visualizes pedestrian movement trajectories using a Variational Autoencoder (VAE) model, while incorporating obstacle constraints. The model is trained on real trajectory data, predicting future movements and visualizing them through animations. The code consists of several components. It first calculates the wall interaction force to apply a penalty when pedestrians get too close to obstacles. The PositionEncoder transforms pedestrian positions into a higher-dimensional space. The VAE model, with an encoder and decoder, learns to compress the trajectory data into a latent space and then reconstruct it. The trajectory loss function combines reconstruction loss, KL divergence, and wall interaction penalties to guide the training process. After training, the model generates and saves new pedestrian trajectories, which are visualized using an animation function that plots both trajectories and obstacles in an interactive way.
state_record_batch is the generated training file, containing pedestrian trajectory data used to train the model. pedestrian_trajectories_with_obstacles is the output generated by the model.
