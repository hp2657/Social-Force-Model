main.py is used to generate simulated data. state record.npy contains the generated simulated data, which is used to train the model. VAE_simple_physics_limitation.py is a VAE generation model that applies simple constraints. pedestrian_trajectories_simple_limitation.mp4 contains pedestrian movement results generated using VAE_simple_physics_limitation.py. VAE_complex_physics_limitation_CPU_only.py is similar to the above VAE generation model but incorporates physical constraints by calculating accelerations caused by collisions between pedestrians and between pedestrians and walls. VAE_complex_physics_limitation_cuda.py is the CUDA version of this model.
